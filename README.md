# 📝 Assignment 3 – Interactive Todo List App

This project is a **Full Stack Assignment** consisting of two implementations of a Todo List application:

* ✅ **Vanilla JavaScript Todo App**
* ⚛️ **React Todo App**

Both versions demonstrate core frontend development concepts including DOM manipulation, state management, and local storage persistence.

---

## 📂 Project Structure

```
assignment-3/
│── todo-vanilla/   # Plain HTML, CSS, JavaScript implementation
│── todo-react/     # React-based implementation
```

---

## 🚀 Features

### 🔹 Vanilla JavaScript App

* Add new tasks
* Display tasks dynamically
* Delete tasks
* Mark tasks as completed (strikethrough)
* Task counter (Total & Completed)
* Local Storage support (data persists on reload)
* Clear all tasks with confirmation
* Console logging for debugging
* (Bonus) Edit task on double-click

---

### 🔹 React App

* Component-based architecture:

  * TodoForm
  * TodoList
  * TodoItem
  * TodoCounter
* State management using `useState`
* Side effects using `useEffect`
* Local Storage integration
* Props & callback functions (parent-child communication)
* Clean and modular code structure
* External CSS styling

---

## 🛠️ Technologies Used

* HTML5

## ⚙️ How to Run the Project

### ▶️ Vanilla JavaScript App

1. Navigate to:

   ```
   cd todo-vanilla
   ```
2. Open `index.html` in your browser

---

### ▶️ React App

1. Navigate to:

   ```
   cd todo-react
   ```
2. Install dependencies:

   ```
   npm install
   ```
3. Start the app:

   ```
   npm start
   ```
